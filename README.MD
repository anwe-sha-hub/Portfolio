# 💼 Portfolio Website  

A modern and responsive **Portfolio Website** built with **HTML & CSS** to showcase my work, skills, and achievements.  
It includes a clean design, project highlights, resume download, and social media links.  


---

- 🖼️ Minimal & modern **design**  
- 📱 Fully **responsive** for all devices  
- 📂 **Projects showcase** section  
- 📑 **Resume download** option  
- 🔗 Integrated **social media links**

- **CSS3** → Styling and layout  
- **JavaScript** *(optional: for future interactions)*
